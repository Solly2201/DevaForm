# Human base — authoring pipeline

The human body asset (`humanoid.body.human`) is **built**, not sculpted by
hand and not generated at runtime. This directory holds the authoring side
of that build. Nothing here ships to the browser: the only runtime artifact
is the GLB under `apps/web/public/assets/humanoid/body/human/1/`.

## Two steps

```
1.  python tools/humanbase/export-makehuman.py      # needs MakeHuman installed
2.  cd apps/web && node scripts/build-human-base.mjs
```

**Step 1** drives MakeHuman's own code (its modifier system and its official
OBJ exporter) to write, into `exports/`:

- `neutral|lean|athletic|powerful.obj` — one body per build variant. The
  variants differ only in girth (Muscle/Weight), so all four share a single
  topology and a single skeleton, which is what makes them usable as morph
  targets.
- `*.mhm` — the MakeHuman model files. These are the human-readable source
  of truth: opening one in MakeHuman reproduces the exported mesh exactly.
- `joints.json` — joint-cube positions, the OBJ→base-mesh vertex map, and
  the version/exporter strings recorded in the asset's provenance.
- `default.mhskel` / `default_weights.mhw` — MakeHuman's CC0 default rig.

**Step 2** turns those into the shipped asset: it groups the rig's 163 bones
onto DevaForm's canonical joints, retargets the A-pose mesh into DevaForm's
rest pose (arms hanging, palms forward) so every existing pose preset and
mudra applies unchanged, normalises to the 1.0 m canonical height, builds
the morph targets, measures the body's own attachment surfaces, and writes
`model.glb`, `asset.json` and `measurements.json`.

## What is committed

The `.mhm` files and `measurements.json` are committed; everything else in
`exports/` is regenerated by step 1 and is ignored by git (about 12 MB of
OBJ and rig data). The built GLB is committed, so using the asset needs
neither MakeHuman nor this pipeline — only rebuilding it does.

## Licensing

Characters exported through the export functionality of an official,
unmodified MakeHuman build are CC0, as are the default skeleton and its
weights. MakeHuman itself is AGPL and is **authoring-time only**: no
MakeHuman code, data format or runtime dependency enters DevaForm.

## Measurements

`measurements.json` records what the built mesh actually is: the derived
skeleton, socket positions, per-variant body measurements, and the
`bodyProfile` block (base values plus per-morph deltas) that the engine
uses to fit clothing and ornaments to this body's real surfaces. It is a
build output — regenerate it, never hand-edit it. The same numbers appear
in the manifest entry in `packages/asset-system/src/manifests/shared.ts`.
